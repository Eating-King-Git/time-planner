# 时间规划师 v0.2.1 · 首个公开版本

时间规划师是一款本地优先的 Windows 桌面任务管理工具，将中文任务输入、重要/紧急四象限、当日时间安排和桌面提醒整合到可置顶的小窗口中。适合个人学习、研究和日常工作安排。

## 本版本提供

- 中文任务输入、时间字段补充、四象限评分解释和手动调整。
- 今天、未来3天、未来7天及长期任务视图。
- 当日自动排程、固定事件冲突提示、提醒与截止后确认。
- 当天完成任务保留显示，未完成普通任务跨日延续。
- 可置顶窗口、紧凑/完整模式和界面缩放。
- 待确认结果记录、自动消失提示和本地 JSON 存储。

## 下载与运行

Windows x64 用户下载 `TimePlanner-v0.2.1-windows.zip`，完整解压后双击 `时间规划师.exe`。无需另装 Node.js。请保留压缩包中的全部运行文件。

开发者可下载 `TimePlanner-v0.2.1-source.zip` 或克隆仓库，使用 Node.js 22 或更新版本运行 `npm ci` 和 `npm start`。

## 使用范围

运行不需要账号或大模型 API。当前没有云同步和后台提醒服务，通知需要应用保持运行。未来视图展示已知事项，自动排程只计算今天。评分和时间比例为经验规则，可手动修正任务分类。

这是早期个人桌面工具，尚未做商业代码签名；不包含个人课表、待办数据库或账户凭据。数据默认位于 `%APPDATA%\time-planner\`，升级前可退出应用并备份此目录。
